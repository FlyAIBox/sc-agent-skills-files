## 规则 0：最低数据资格要求

渠道只有在分析期内具有**至少 50 次转化**时才有资格进行预算调整。

低于阈值的渠道：分类为 **数据不足 -> 维持不变**。

---

## 规则 1：渠道分类

将每个渠道准确分类到一个类别中。**按顺序**应用规则（首次匹配优先）：

### 暂停（100% 减少）
满足任一条件即触发：
- 用户说明渠道已连续 3 周或更长时间表现为负
- 用户说明经过 3 周或更长时间的优化努力后仍无改善

### 大幅减少（45% 减少）
满足任一条件即触发：
- ROAS < 目标的 50% 且净利润 <= 0
- CPA > 最大值的 150% 且净利润 <= 0
- 三者同时不达标：ROAS < 100% 且 CPA > 100% 且净利润 <= 0
- 用户说明渠道已连续 2 周表现为负

### 增加（使用用户指定上限，默认 15%）
必须满足所有条件：
- ROAS >= 目标的 115%
- CPA <= 最大值的 80%
- 净利润 > 0

### 小幅减少（25% 减少）
满足任一条件即触发（如果尚未被分类）：
- ROAS < 目标的 80%
- CPA > 最大值的 120%

### 维持不变（0% 变化）
不符合以上任何标准。

## 规则 2：计算预算变化

### 步骤 1：计算减少额（全额应用）
```
大幅减少：减少额 = 当前支出 * 0.45
小幅减少：减少额 = 当前支出 * 0.25
```

### 步骤 2：计算释放的预算
```
释放预算 = sum(所有减少额)
```

### 步骤 3：分配给增加渠道
按净利润比例分配：
```
权重 = 渠道净利润 / sum(所有增加渠道的净利润)
建议增加额 = 释放预算 * 权重
```

### 步骤 4：应用上限

**单渠道上限：** 如提供用户指定值则使用，否则默认为 15%。
```
最大增加额 = 当前支出 * 增加上限
最终增加额 = min(建议增加额, 最大增加额)
```

**用户重新分配限制**（如果指定）：
- 仅适用于**增加额**，不适用于减少额
- 如果 sum(建议增加额) > 用户限制：按比例缩减增加额
```
缩放因子 = 用户限制 / sum(建议增加额)
最终增加额 = 建议增加额 * 缩放因子
```

### 步骤 5：计算未分配节余
```
未分配额 = 释放预算 - sum(最终增加额)
```
报告为"可用作储备"。

## 多周调整

如果用户提供历史背景信息，调整分类：

| 用户描述 | 调整 |
|-----------|------------|
| "渠道 X 已连续 2 周或更长时间表现为负" | 升级为大幅减少或暂停 |
| "渠道 X 已连续 3 周或更长时间表现为负" | 暂停（将预算设为 $0） |
| "我们上周已更改渠道 X 的预算" | 覆盖为维持不变（允许 5-7 天稳定） |
| "渠道 X 相比上周有所改善" | 可将小幅减少升级为维持不变 |

没有历史背景时，仅使用单周分类。

## 决策矩阵

| 条件 | 分类 | 变化 |
|-----------|----------------|--------|
| 连续 3 周或更长时间为负（用户说明） | 暂停 | -100% |
| 3 周或更长时间无改善（用户说明） | 暂停 | -100% |
| 连续 2 周为负（用户说明） | 大幅减少 | -45% |
| ROAS < 50% 且净利润 <= 0 | 大幅减少 | -45% |
| CPA > 150% 且净利润 <= 0 | 大幅减少 | -45% |
| ROAS < 100% 且 CPA > 100% 且净利润 <= 0 | 大幅减少 | -45% |
| ROAS >= 115% 且 CPA <= 80% 且净利润 > 0 | 增加 | +15% 上限 |
| ROAS < 80% | 小幅减少 | -25% |
| CPA > 120% | 小幅减少 | -25% |
| 所有其他情况 | 维持不变 | 0% |

## 必需的输出格式

### 1. 分类表格
| 渠道 | ROAS | 占目标% | CPA | 占最大值% | 净利润 | 分类 |

### 2. 计算步骤
展示：释放预算、分配权重、建议增加额与上限后增加额、未分配节余。

### 3. 最终重新分配表格
| 渠道 | 当前预算 | 变化 | 新预算 | 分类 |

如果未分配额 > 0，包含"储备"行。
