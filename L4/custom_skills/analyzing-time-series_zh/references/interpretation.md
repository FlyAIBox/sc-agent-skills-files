# 快速参考：解释时间序列诊断

## 平稳性测试

### ADF (Augmented Dickey-Fuller)

| p 值 | 解释 |
|---------|----------------|
| ≤ 0.01  | 强有力的平稳证据 |
| ≤ 0.05  | 平稳（拒绝原假设） |
| > 0.05  | 非平稳（无法拒绝） |

**原假设：** 序列具有单位根（非平稳）

### KPSS (Kwiatkowski-Phillips-Schmidt-Shin)

| p 值 | 解释 |
|---------|----------------|
| > 0.10  | 平稳（无法拒绝） |
| > 0.05  | 可能平稳 |
| ≤ 0.05  | 非平稳（拒绝原假设） |

**原假设：** 序列是平稳的（与 ADF 相反）

### 综合解释

| ADF | KPSS | 结论 |
|-----|------|------------|
| 平稳 | 平稳 | 确认平稳 |
| 非平稳 | 非平稳 | 确认非平稳 |
| 平稳 | 非平稳 | 趋势平稳（需差分或去趋势） |
| 非平稳 | 平稳 | 差分平稳（可能需要差分） |

### 差分 (d)

| d 值 | 含义 | 常见原因 |
|---------|---------|---------------|
| 0 | 已经平稳 | 平稳过程 |
| 1 | 需要一阶差分 | 趋势，随机游走 |
| 2 | 需要二阶差分 | 二次趋势，I(2) 过程 |

**警告：** 如果 d=2 仍然非平稳，请考虑：
- 数据中的结构性断点
- 非线性趋势
- 机制变化

## 季节性

### 季节性强度

| 强度 | 解释 |
|----------|----------------|
| 0.0 - 0.1 | 无有意义的季节性 |
| 0.1 - 0.3 | 弱季节性 |
| 0.3 - 0.6 | 中等季节性 |
| 0.6 - 0.9 | 强季节性 |
| > 0.9 | 非常强的季节性 |

### 常见季节性周期

| 数据频率 | 典型周期 | 含义 |
|----------------|----------------|---------|
| 小时 | 24 | 日循环 |
| 小时 | 168 | 周循环 (24 × 7) |
| 日 | 7 | 周循环 |
| 日 | 365 | 年循环 |
| 周 | 52 | 年循环 |
| 月 | 12 | 年循环 |
| 季度 | 4 | 年循环 |

## 可预测性 (Ljung-Box 测试)

### 解释

| p 值 | 解释 |
|---------|----------------|
| ≤ 0.01  | 强自相关 - 高度可预测 |
| ≤ 0.05  | 显著自相关 - 可预测 |
| > 0.05  | 无显著自相关 - 可能是白噪声 |
| > 0.10  | 可能是白噪声 - 不可预测 |

**原假设：** 无自相关（白噪声）

### 这意味着什么

- **可预测：** 过去的值包含有关未来值的信息
- **不可预测（白噪声）：** 未来值是随机的，无法从历史中预测

## 变换建议

### Box-Cox Lambda 解释

| Lambda (λ) | 推荐变换 |
|------------|----------------------|
| λ ≈ -1 | 倒数 (1/y) |
| λ ≈ -0.5 | 倒数平方根 (1/√y) |
| λ ≈ 0 | 对数变换 (log y) |
| λ ≈ 0.5 | 平方根 (√y) |
| λ ≈ 1 | 无需变换 |
| λ ≈ 2 | 平方 (y²) |

### 何时变换

| 症状 | 可能的变换 |
|---------|------------------|
| 方差随水平增加 | 对数或平方根 |
| 右偏分布 | 对数 |
| 乘性季节性 | 对数 |
| 异方差残差 | Box-Cox |

### 要求

- **对数变换：** 所有值必须为正 (y > 0)
- **Box-Cox：** 所有值必须为正
- **平移：** 如果数据有零或负数，请先加常数

## ACF/PACF 解释

### 阅读图表

| 模式 | ACF | PACF | 建议模型 |
|---------|-----|------|-----------------|
| AR(p) | 逐渐衰减 | 在滞后 p 后截尾 | AR(p) |
| MA(q) | 在滞后 q 后截尾 | 逐渐衰减 | MA(q) |
| ARMA | 逐渐衰减 | 逐渐衰减 | ARMA(p,q) |
| 季节性 | 在季节性滞后处出现峰值 | 在季节性滞后处出现峰值 | SARIMA |

### 置信带

- 阴影带之外的值具有统计显著性
- 默认带为 95% 置信度 (±1.96/√n)
- 预期约 5% 的滞后会因偶然原因超出带

### 常见模式

**AR(1)：** PACF 在滞后 1 处有峰值，ACF 指数衰减
**MA(1)：** ACF 在滞后 1 处有峰值，PACF 指数衰减
**季节性 (周期=12)：** 在滞后 12, 24, 36... 处有峰值

## 模型选择指南

### 基于诊断

| 条件 | 推荐方法 |
|-----------|---------------------|
| 平稳，无季节性 | ARMA |
| 非平稳，无季节性 | ARIMA(p,d,q) |
| 平稳，季节性 | SARIMA with D=0 |
| 非平稳，季节性 | SARIMA(p,d,q)(P,D,Q)m |
| 强趋势，弱季节性 | 指数平滑 (Holt) |
| 强趋势，强季节性 | Holt-Winters 或 SARIMA |
| 不可预测 | 考虑外部回归量或接受限制 |

### ARIMA 阶数经验法则

- 从平稳性测试的 d 开始
- 使用 PACF 截尾确定 p (AR 阶数)
- 使用 ACF 截尾确定 q (MA 阶数)
- 保持 p + q ≤ 4 以保持简洁
- 使用 AIC/BIC 进行最终选择
