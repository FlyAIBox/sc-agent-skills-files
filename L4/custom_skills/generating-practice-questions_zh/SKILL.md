# 练习题生成器

根据讲义生成综合练习题，以测试学生对学习目标和关键概念的理解。

## 输入 

**支持的格式**：LaTeX (.tex), PDF, Markdown (.md), 纯文本 (.txt)

- **PDF**：使用 `pdfplumber` 提取文本

- **LaTeX**：作为文本读取，去除导言区（`\begin{document}` 之前的内容），保留数学环境（`$...$`, `\[...\]`, `\begin{equation}` 等）

- **Markdown/文本**

**要提取的内容**：

1. **学习目标** - 通常在开头：“本次讲座后，你应该能够……”或在部分中：“学习成果”，“目标”，“目的”。如果不存在，则从主要主题推导。
2. **主要主题** - 章节标题、粗体术语、定义、算法。
3. **示例** - 用于问题中的现实场景。

## 问题结构

按此顺序生成问题：

1. **判断题**（每个学习目标一个，如果没有目标则 3-5 个）
2. **解释性问题**（3-5 个涵盖主要主题）
3. **编码问题**（1 个算法实现或概念模拟）
4. **用例**（1 个现实应用）

对于每种问题类型，请遵循以下准则，切勿包含答案。

## 问题准则

### 类型 1：判断题

测试事实理解和常见误解。

**覆盖范围**：

- 每个学习目标一个，如果没有目标则 3-5 个涵盖主要主题

**难度递进**：

- 从 1-2 个简单的定义性问题开始
- 包括 2-3 个基于推理的问题，要求应用概念或测试概念之间的关系

**质量标准**：

- 只有一种正确解释的明确性
- 语言清晰，没有复杂的嵌套从句
- 答案直接在讲义中找到
- 错误答案揭示常见误解

**示例**：

- *简单*：“在监督学习中，训练数据包括输入特征及其对应的标签。”
- *中等*：“训练准确率高但测试准确率低的模型可能欠拟合数据。”

### 类型 2：解释性问题

通过要求学生阐述概念、比较方法和解释推理来测试更深层次的理解。

**主题选择**：

- 选择 3-5 个主要主题（关键算法及其实现、方法的优点/局限性、概念之间的关系）
- 避免重复：如果主题出现在判断题中，请询问*不同的方面*

**问题表述**：

- “解释……” - 要求用学生的话描述
- “比较和对比……” - 测试对差异的理解
- “为什么……” - 测试因果推理
- “优点/缺点是什么……” - 测试批判性分析
- “描述步骤……” - 测试程序性知识

**质量标准**：

- 开放式但重点突出
- 不能用简单的 是/否 回答
- 需要 3-5 句话才能很好地回答

**示例**：

- “解释偏差-方差权衡。增加模型复杂度如何影响偏差和方差？”
- “比较 K-最近邻和决策树在决策边界、训练时间和预测时间方面的差异。”

### 类型 3：编码问题

通过代码测试实际实现。

**范围**：

- 讲座中讨论的算法实现
- 概念或过程的模拟
- 必须仅使用讲座知识即可实现
- 此题应耗费准备好的学生 15-30 分钟

**所需结构**：

1. 明确的目标
2. 分步说明（3-5 步）
3. 函数签名（如适用）
4. 带有输入/输出示例的预期行为
5. 提示（可选但有帮助）

**语言**：

- Python（默认）带标准库。
- 如果使用外部库：NumPy, pandas, matplotlib, scikit-learn。
- 不应要求高级 Python 特性

### 类型 4：用例问题

测试应用讲义中解释的概念或算法到现实场景的能力。

**组件**：

1. **背景** - 现实场景描述
2. **数据描述** - 可用数据（如果需要，提供生成代码）
3. **任务** - 需要完成什么
4. **约束**（可选） - 时间、空间、准确性要求
5. **提示**（2-3 个） - 指导而不给出解决方案
6. **库** - 可以使用 scikit-learn, pandas, NumPy

**数据生成**：如果需要，提供简单、清晰的代码来生成适当的数据。

## 输出格式指南

输出格式取决于用户请求（LaTeX, PDF, Markdown, 纯文本）。

**所有格式的通用结构**：

1. 文档名称标题
2. 说明部分
3. 第 1 部分：判断题（按顺序编号）
4. 第 2 部分：解释性问题（按顺序编号）
5. 第 3 部分：编码问题（带步骤、签名、示例、提示）
6. 第 4 部分：用例应用（带场景、数据、任务、要求、提示）

**对于特定格式**：对于 LaTeX 和 Markdown 文档结构，请使用以下模板（在 `assets/` 文件夹中）：
- `questions_template.tex` - 完整的 LaTeX 文档结构和格式
- `markdown_template.md` - 完整的 Markdown 文档结构

## 支持资源

**参考资料**（在 `references/` 文件夹中）：

- `examples_by_topic.md` - ML 主题（算法、预处理、评估等）的特定领域问题示例
