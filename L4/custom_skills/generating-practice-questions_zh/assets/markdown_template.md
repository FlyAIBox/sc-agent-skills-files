# 练习题 Markdown 模板

生成 Markdown 格式的练习题时请使用此模板。

```markdown
# [文档标题] 练习题

## 说明

这些练习题旨在测试你对 [课程/文档名称] 中涵盖的材料的理解。请仔细思考每个问题并展示你的推理过程。

---

## 第一部分：判断题

**问题 1:** [问题文本]

**问题 2:** [问题文本]

**问题 3:** [问题文本]

<!-- 根据学习目标添加更多判断题 -->

---

## 第二部分：简答题

**问题 4:** [问题文本]

**问题 5:** [问题文本]

**问题 6:** [问题文本]

**问题 7:** [问题文本]

<!-- 总共添加 3-5 个简答题 -->

---

## 第三部分：编程题

**问题 8: [描述性标题]**

[简要描述需要实现的内容]

**步骤:**
1. [第一个主要步骤]
2. [第二个主要步骤]
3. [第三个主要步骤]
4. [测试步骤]

**函数签名:**
```python
def function_name(param1, param2) -> return_type:
    """
    简要描述函数的功能
    
    Args:
        param1: 描述
        param2: 描述
    
    Returns:
        返回值描述
    """
    pass
```

**示例:**
```python
# 输入
input_example

# 输出
output_example
```

**提示:**
- [有用的提示 1]
- [有用的提示 2]
- [有用的提示 3]

---

## 第四部分：用例应用

**问题 9: [用例标题]**

**场景:**

[2-4 句话描述现实场景]

**数据:**

[描述数据或生成数据的代码]

```python
import numpy as np
import pandas as pd

# 生成样本数据
# [数据生成代码]
```

**任务:**

[具体要求 - 需要完成什么]

**要求:**
- [要求 1]
- [要求 2]
- [要求 3]

**提示:**
- [提示 1 - 指导方法]
- [提示 2 - 实现建议]
- [提示 3 - 重要考虑因素]
```

## 格式指南

- 使用 `**粗体**` 标记问题编号和标签
- 使用代码块 (\`\`\`python) 标记所有代码片段
- 使用 `---` 水平线分隔主要部分
- 所有部分的问题顺序编号
- 在部分之间包含空行以提高可读性
