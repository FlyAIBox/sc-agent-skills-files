# 按主题分类的问题示例

特定领域的示例，用于指导常见机器学习主题的问题生成。

## 机器学习基础

### 学习类型

**判断题示例**：

- “在监督学习中，模型从包含输入特征及其对应输出的标记数据中学习。”（对）
- “无监督学习需要标记数据来识别数据集中的模式。”（错）
- “强化学习涉及代理通过试错以及奖励和惩罚进行学习。”（对）

**解释性示例**：

- “解释监督学习、无监督学习和强化学习之间的主要区别。为每种学习提供一个应用示例。”
- “描述什么样的问题适合分类而不是回归。输出有何不同？”

### 过拟合和欠拟合

**判断题示例**：

- “在训练数据上表现良好但在测试数据上表现不佳的模型是过拟合的。”（对）
- “增加模型复杂度总是能提高泛化性能。”（错）
- “欠拟合模型具有高偏差和低方差。”（对）

**解释性示例**：

- “解释偏差-方差权衡。模型复杂度如何影响每个部分？”
- “描述三种防止机器学习模型过拟合的技术。”

- “两个垂直向量的点积为零。”（对）
- “向量的欧几里得范数表示其大小或长度。”（对）

**解释性示例**：

- “解释为什么点积对于测量特征向量之间的相似性很有用。余弦相似度与此有何关系？”

**编码示例**：

```latex
\textbf{问题：欧几里得距离计算}

实现一个函数来计算两个表示为 NumPy 数组的点之间的欧几里得距离。

\begin{enumerate}
    \item 接受两个等长的向量作为输入
    \item 计算逐元素差
    \item 将每个差平方，求和，然后取平方根
    \item 返回距离作为标量
\end{enumerate}
```

## 数据预处理

### 特征缩放

**判断题示例**：

- “标准化将特征转换为具有零均值和单位方差。”（对）

**解释性示例**：

```latex
\textbf{问题：实现标准化}

实现一个函数来标准化特征矩阵（零均值，单位方差）。

\begin{enumerate}
    \item 计算每个特征（列）的均值
    \item 计算每个特征的标准差
    \item 减去均值并除以标准差
    \item 处理标准差为零的边缘情况
\end{enumerate}
```

**用例示例**：

## 模型评估

### 训练/测试分割和交叉验证

**判断题示例**：

- “使用相同的数据进行训练和评估可以准确估计模型性能。”（错）
- “K-折交叉验证比单一的训练/测试分割提供了更稳健的模型性能估计。”（对）
- “测试集绝不应用于模型选择或超参数调整。”（对）

**解释性示例**：

- “解释为什么我们需要单独的训练集、验证集和测试集。每个集在模型开发过程中起什么作用？”
- “描述 5-折交叉验证的工作原理。与简单的留出法相比，它有什么优势？”

### 分类指标

**判断题示例**：

- “准确率始终是评估分类模型的最佳指标。”（错 - 特别是对于不平衡数据）
- “精确率衡量的是预测为正的样本中实际正确的比例。”（对）
- “召回率高的模型如果预测出许多假阳性，其精确率可能会很低。”（对）

**解释性示例**：

- “解释精确率和召回率的区别。在什么情况下你会优先考虑其中之一？”
- “描述混淆矩阵显示的内容，以及如何从中计算准确率、精确率、召回率和 F1 分数。”

**编码示例**：

```latex
\textbf{问题：实现混淆矩阵指标}

给定预测标签和真实标签，从头计算分类指标。

\begin{enumerate}
    \item 统计真阳性 (TP)、假阳性 (FP)、真阴性 (TN) 和假阴性 (FN)
    \item 计算准确率：(TP + TN) / (TP + TN + FP + FN)
    \item 计算精确率：TP / (TP + FP)
    \item 计算召回率：TP / (TP + FN)
    \item 计算 F1 分数：2 * (precision * recall) / (precision + recall)
\end{enumerate}
```

**用例示例**：

```latex
\textbf{问题：信用卡欺诈检测评估}

\textbf{场景：}
一家银行部署了一个欺诈检测模型。在 10,000 笔交易中，实际有 50 笔是欺诈。该模型将 80 笔交易标记为欺诈，正确识别了 40 笔实际欺诈案例。

\textbf{任务：}
1. 构建混淆矩阵
2. 计算准确率、精确率、召回率和 F1 分数
3. 解释为什么仅凭准确率在这个问题上具有误导性
4. 建议银行应优先考虑哪个指标以及原因
```

## K-最近邻 (KNN)

### 算法基础

**判断题示例**：

- “KNN 是一种懒惰学习算法，因为它在训练期间不建立显式模型。”（对）
- “KNN 预测的时间复杂度是 O(1)，因为没有训练阶段。”（错 - 预测是 O(nm)，其中 n 是样本数，m 是特征数）
- “增加 KNN 中的 k 总是能提高模型准确率。”（错 - 存在最优的 k）
- “KNN 可用于分类和回归任务。”（对）

**解释性示例**：

- “解释为什么 KNN 被称为‘懒惰学习器’或‘基于实例的学习器’。这对训练和预测时间有什么影响？”
- “描述维度灾难并解释它为何特别影响 KNN。随着维度的增加，距离会发生什么变化？”
- “比较 KNN 中小 k 与大 k 对偏差-方差权衡的影响。”

### 距离度量

**判断题示例**：

- “欧几里得距离是唯一可用于 KNN 的距离度量。”（错）
- “曼哈顿距离是对每个维度的绝对差值求和。”（对）
- “余弦相似度测量两个向量之间的角度而不是它们的大小。”（对）

**解释性示例**：

- “比较欧几里得距离和曼哈顿距离。在什么情况下可能首选曼哈顿距离？”
- “解释在测量数据点之间的相似性时，何时余弦相似度会是比欧几里得距离更好的选择。”

**编码示例**：

```latex
\textbf{问题：实现 KNN 分类器}

从头实现 K-最近邻分类。

\begin{enumerate}
    \item 计算测试点到所有训练点的欧几里得距离
    \item 找到 k 个最小距离的索引
    \item 检索 k 个最近邻居的标签
    \item 返回最常见的标签（多数投票）
    \item 使用不同的 k 值进行测试
\end{enumerate}

\textbf{函数签名：}
\begin{verbatim}
def knn_classify(X_train, y_train, x_test, k):
    """
    使用 KNN 对单个测试点进行分类。

    Args:
        X_train: 训练特征 (n_samples, n_features)
        y_train: 训练标签 (n_samples,)
        x_test: 测试点 (n_features,)
        k: 邻居数量

    Returns:
        预测的类标签
    """
\end{verbatim}
```

**用例示例**：

```latex
\textbf{问题：鸢尾花物种分类}

\textbf{场景：}
一位植物学家希望根据花萼长度、花萼宽度、花瓣长度和花瓣宽度的测量值自动将鸢尾花分类为三个物种。

\textbf{数据：}
使用 sklearn 的 iris 数据集：
\begin{verbatim}
from sklearn.datasets import load_iris
iris = load_iris()
X, y = iris.data, iris.target
\end{verbatim}

\textbf{任务：}
1. 将数据分为训练集 (70%) 和测试集 (30%)
2. 标准化特征
3. 使用 5-折交叉验证找到最佳 k (尝试 k = 1, 3, 5, 7, 9)
4. 绘制训练和验证准确率与 k 的关系图，以可视化偏差-方差权衡
5. 报告使用最佳 k 的测试准确率

\textbf{提示：}
\begin{itemize}
    \item 使用 sklearn.preprocessing 中的 StandardScaler
    \item 使用 cross_val_score 和 cv=5 进行交叉验证
    \item 小 k 导致过拟合，大 k 导致欠拟合
\end{itemize}
```

## 决策树

### 树结构和分裂

**判断题示例**：

- “决策树根据特征值分裂数据以创建同质子集。”（对）
- “基尼不纯度衡量随机选择的元素被错误分类的概率。”（对）
- “决策树需要特征缩放才能正常工作。”（错 - 树是尺度不变的）
- “没有深度限制的决策树总是能达到 100% 的训练准确率。”（对 - 如果特征可以区分所有样本）

**解释性示例**：

- “解释决策树如何选择在每个节点上分裂哪个特征。基尼不纯度或信息增益起什么作用？”
- “描述决策树边界的几何解释。为什么它们总是轴对齐的？”
- “解释为什么深层决策树倾向于过拟合，以及修剪或限制树深度如何有助于防止这种情况。”

### 树超参数

**判断题示例**：

- “限制决策树的最大深度有助于防止过拟合。”（对）
- “最小样本分裂为 1 将允许树生长直到每个叶子有一个样本。”（对）
- “决策树只能处理分类特征，不能处理连续特征。”（错）

**解释性示例**：

- “描述 max_depth 超参数如何影响决策树中的偏差-方差权衡。”
- “解释预剪枝（停止标准）和后剪枝技术之间的区别。”

**编码示例**：

```latex
\textbf{问题：计算基尼不纯度}

实现一个函数来计算节点的基尼不纯度。

\begin{enumerate}
    \item 统计节点中每个类的频率
    \item 计算每个类的比例：$p_c = n_c / n_{total}$
    \item 计算基尼：$G = 1 - \sum_{c} p_c^2$
    \item 在示例上测试：[0, 0, 1, 1, 1] 应得出 Gini = 0.48
\end{enumerate}

\textbf{函数签名：}
\begin{verbatim}
def gini_impurity(labels):
    """
    计算一组标签的基尼不纯度。

    Args:
        labels: 类标签数组

    Returns:
        基尼不纯度值在 0 和 0.5 之间（对于二元）
    """
\end{verbatim}
```

**用例示例**：

```latex
\textbf{问题：贷款违约预测}

\textbf{场景：}
一家银行希望根据申请人的信用记录、收入和贷款金额预测其是否会违约。模型应该是可解释的，以便信贷员可以向申请人解释决定。

\textbf{数据：}
\begin{verbatim}
import numpy as np
import pandas as pd

np.random.seed(42)
n = 500

data = {
    'credit_score': np.random.randint(300, 850, n),
    'annual_income': np.random.exponential(50000, n),
    'loan_amount': np.random.exponential(15000, n),
    'debt_ratio': np.random.uniform(0, 0.8, n)
}
df = pd.DataFrame(data)

# 低信用分、高负债率意味着更高的违约概率
default_prob = 0.1 + 0.3 * (df['credit_score'] < 600) + 0.2 * (df['debt_ratio'] > 0.5)
df['default'] = (np.random.random(n) < default_prob).astype(int)
\end{verbatim}

\textbf{任务：}
1. 训练一个 max_depth=3 的决策树分类器
2. 可视化树结构
3. 识别预测违约的最重要特征
4. 解释树学到的三个决策规则
5. 讨论为什么在这个应用中可能首选浅层树

\textbf{提示：}
\begin{itemize}
    \item 使用 sklearn.tree.plot_tree() 或 export_text() 进行可视化
    \item 特征重要性可通过 tree.feature_importances_ 获得
    \item 考虑准确性和可解释性之间的权衡
\end{itemize}
```

```latex
\textbf{问题：实现 Sigmoid 函数}

实现 sigmoid 函数并使用它将逻辑回归输出转换为概率。

\begin{enumerate}
    \item 实现：$\sigma(z) = \frac{1}{1 + e^{-z}}$
    \item 处理 z 为大负数时的数值溢出

\end{enumerate}
```

## 正则化

### Ridge 和 Lasso 回归

**判断题示例**：

- “Ridge 回归 (L2) 倾向于将系数缩小到零，但很少使它们完全为零。”（对）
- “Lasso 回归 (L1) 可以通过将某些系数设置为完全为零来进行特征选择。”（对）

- “比较 Ridge (L2) 和 Lasso (L1) 正则化。什么时候你会选择其中一种？”

```latex

\textbf{场景：}
你正在建立一个具有许多特征（大小、卧室、位置评分等）的模型来预测房价。有些特征可能高度相关或不相关。

\textbf{任务：}
1. 训练线性回归、Ridge 和 Lasso 模型
2. 使用交叉验证为 Ridge 和 Lasso 找到最佳 lambda
```

## 不同讲座主题的提示

### 对于重算法的讲座（KNN、决策树）

- 编码问题集中在实现核心算法上
- 用例应显示使用真实数据的实际应用
- 判断题测试边缘情况、复杂度和超参数

### 对于重理论的讲座（偏差-方差、评估）

- 更多解释性问题测试概念理解
- 判断题测试常见误解
- 编码问题计算指标或演示概念
- 用例演示理论在实践中为何重要

### 对于重数学的讲座（线性代数、优化）

- 判断题测试数学属性
- 解释性问题将数学与 ML 应用联系起来
- 编码问题实现数学运算
- 用例显示数学如何支持 ML 解决方案

### 对于预处理讲座（缩放、编码）

- 判断题测试何时需要预处理
- 解释性问题比较不同的技术
- 编码问题从头实现预处理
- 用例显示预处理对模型性能的影响
